# Puzzle Runner

Цей проект знаходить найдовший ланцюжок чисел, де кожне наступне число продовжує попереднє за двома останніми цифрами.

Наприклад, маємо такі рядки із числами:

608017, 248460, 962282, 994725, 177092

Рішення:

Аналізуючи кінцеві частини, можна скласти такий ланцюжок:

248460 & 608017 & 177092 -> 2484(60)80(17)7092

Таким чином найбільша послідовність і відповідь буде: 24846080177092

Кожен фрагмент має бути використаний тільки 1 раз.

## Запуск локально

```bash
ruby puzzle_solver.rb source.txt
```

## Запуск через Docker

```bash
docker build -t puzzle-runner .
docker run --rm -it puzzle-runner
```

Або без попереднього build:

```bash
docker run --rm -v "$PWD":/app -w /app ruby:3.2-slim ruby puzzle_solver.rb source.txt
```
